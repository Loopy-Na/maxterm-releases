# MaxTerm 설치 파일

AI 개발 터미널 MaxTerm 의 배포 전용 저장소입니다. 소스 코드는 없고 [Releases](https://github.com/Loopy-Na/maxterm-releases/releases) 에 설치 파일만 올립니다.

## 설치

1. [최신 릴리스](https://github.com/Loopy-Na/maxterm-releases/releases/latest)에서 `MaxTerm-<버전>-arm64.dmg` 를 받아 열고 MaxTerm 을 응용 프로그램 폴더로 끌어 넣습니다.
2. 처음 열 때 macOS 가 막으면 Finder 에서 MaxTerm 을 **우클릭 → 열기** 합니다(한 번만).
3. 이후 업데이트는 MaxTerm 이 30분마다 이 저장소를 확인해 자동으로 받습니다. 로그인은 필요 없습니다.
